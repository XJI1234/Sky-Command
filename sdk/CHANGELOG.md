# Changelog

## 0.2.18 - 2026-10-26

### Added
- 工作流连接快照增加只读 navigation：机头航向、定位采样身份、单调时钟年龄、GPS 有效性和原始高度；高度基准明确为 unknown。
- 配套操作台新增独立飞机图层，支持多机、只读详情和 5 秒定位过期。

## 0.2.17 - 2026-10-22

### Fixed
- 回传还在检查电脑已有照片、命令尚未发出时，停止也会取消这次回传，不再随后把 `camera.photo.fetch` 发给手机。

## 0.2.16 - 2026-10-22

### Fixed
- 回传被停止后，照片进度收成 `stopped`。此前终态快照丢掉进度，操作台会一直显示「停止回传」。

## 0.2.15 - 2026-10-22

### Fixed
- 生产装配把 `stopFetch` 交给照片控制。此前停止回传只在桌面返回 `DEPENDENCY_FAILURE`，`camera.photo.fetch.stop` 到不了手机。

## 0.2.14 - 2026-10-22

### Added
- 回传进行中可以停止。桌面下发 `camera.photo.fetch.stop`，手机调用大疆停止原图下载、停止拉列表并退出回放。

## 0.2.13 - 2026-10-22

### Fixed
- 启动图传和回传照片重新要求 AirLink 与主相机已连接。MSDK 的成功回调不能代替画面，源未就绪时在桌面和手机调用 DJI 前拒绝。

## 0.2.12 - 2026-10-22

### Fixed
- 图传启动和停止在 DJI 成功回调后返回 `SUCCEEDED`，操作台可以像飞行和拍照一样显示 `onSuccess`。

## 0.2.11 - 2026-10-22

### Changed
- 图传启动命令尚未返回时，桌面不再因 AirLink 或主相机断开把这次启动写成源不可用，避免盖住 DJI 回调。

## 0.2.10 - 2026-10-22

### Changed
- 暂时取消启动图传和回传照片对 AirLink、主相机连接状态的本地门禁。手机已就绪即可把命令交给 DJI，由其错误回调说明原因。拍照仍要求主相机已连接。

## 0.2.9 - 2026-10-22

### Fixed
- 断线后又建立的新航线，不再接收上一轮暂存回执；任务编号变了就不再把新任务写成传输失败。
- 被暂停或停止抢占的启动超时不再当成启动成功。停止被拒绝时，按请求顺序恢复已经确认的暂停或继续，而不是退回过时的暂停中。
- 飞控确认回执在会话更换、断线重连或已有更新确认时，不再改写降落意图，也不清掉新确认。工作流关闭后迟到回执不再改快照。
- 多架飞机的失败图传同时停止，不再等待第一架回执。

## 0.2.8 - 2026-10-21

### Fixed
- 同名航线再次执行时保留旧里程碑去重记录，避免绑定上一轮任务身份并忽略本轮结束或中断。
- 匹配任务的终态可以在暂停、继续、停止期间立即收敛，迟到命令回执不再覆盖终态或新任务。

## 0.2.7 — 2026-10-19

### Fixed
- 原图回传前按当前磁盘内容刷新去重清单，电脑外部删除照片后再次点击回传可补齐缺失文件，保留的照片仍跳过。
- 磁盘目录读取失败时明确结束准备阶段，不再向手机发送过期的已回传清单。

## 0.2.6 — 2026-10-18

### Fixed
- 同一飞机的多个 HTTP-FLV 观看连接独立管理，避免新观看请求关闭已有画面；关闭一个观看者只清理本次响应。
- 传入第三方播放会话前剔除未知查询和非法页面标识，避免默认连接日志记录原始输入。

### Added
- 观看连接开闭原因、字节/队列计数和 RTMP 视频包到达间隔诊断，不改变手机推流与飞控命令。

## 0.2.5 — 2026-10-16

### Fixed
- 手机上传航线时，多条进度遥测、诊断日志及成功回执可能在一次 TCP 读取内到达。Node 中继逐条让出事件循环处理，避免合法突发触发 `inbound-overflow` 断连并丢失上传回执；原有队列上限与溢出保护保持不变。

## 0.2.2 — 2026-10-16

### Added
- Node 与 desktop 入口提供局域网自动发现广播及持久电脑身份，供非 Electron 宿主接线。

### Fixed
- 合并 RTMP 握手前断连清理修复，保留原有 DJI 时间戳回绕与播放时间线修复。
- 修复 desktop CommonJS 包内 `createRequire` 的模块路径，确保 Node ESM 与 CommonJS 宿主均可加载。

## 0.2.1 — 2026-10-15

### Added
- 控制网关放行 `pairing.start` 与 `pairing.stop`，和桌面版中继一样把对频命令交给手机。
- `./desktop` 导出桌面版应用、界面网关和图传端口，网站可以跑同一套飞机操作。

## 0.2.0 — 2026-10-15

### Added
- `camera.photo.fetch` 的照片进度从手机中继转发到浏览器 `onPhotoProgress`。
- 命令上的 `timeoutMs` 会同时延长浏览器等待和中继命令超时，照片回传不再被 35 秒控制超时打断。

## 0.1.0 — 2026-10-07

### Added
- Vue 3 与 React 18/19 共用的设备客户端和订阅封装。
- Node 安卓中继监听与浏览器控制网关，复用 v1 协议。
- ESM、CommonJS、TypeScript 声明和独立 npm 安装包。
- 配对状态、设备设置、飞行、航线、直播、媒体与照片业务的按需导入入口。
- 会话保护、连接恢复、命令超时、二进制任务上传与安装包/浏览器验证。
