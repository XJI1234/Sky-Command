# 生产源码有限集合盘点二级模块契约

## 1. 唯一职责

本模块只负责从桌面端和手机端生产源码中确定性地发现公开有限状态、枚举和封闭变体集合，并与已审阅基线比较。它不执行业务命令，不判断状态转换是否正确，也不自动批准源码变化。

## 2. 输入与输出

输入是两个明确的源码根目录。桌面端只扫描生产 TypeScript，忽略测试及 `cross-runtime-e2e` 自身；手机端只扫描 `src/main` 下 Kotlin，忽略验证替身。

输出包含排序后的相对路径、运行时、集合种类、名称和值，以及对完整清单计算的 SHA-256 摘要。输出不得包含绝对路径。

## 3. 失败规则

源码集合与 `baseline.json` 任一项不一致时测试必须失败。基线只能在人工确认新增或删除的有限集合已经具有相应验证证据后更新，不能在测试中自动改写。

## 4. 边界

本模块证明“有限集合没有静默变化”，不单独证明每个转换均正确。转换正确性由独立模型、公开接口分支覆盖和跨运行时场景共同证明。
