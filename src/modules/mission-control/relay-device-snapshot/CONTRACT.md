# 中继设备快照解析模块契约

状态：已批准实施

## 1. 职责

`relay-device-snapshot` 是 `mission-control` 内部的纯二级模块。它只负责把来自中继链路的未知值安全地投影为一组可信的在线设备标识。

它不订阅中继、不保存前一次快照、不判断设备是否断线、不改变任务阶段、不发送命令，也不依赖 WebSocket、Node、Electron、DJI、Android 或界面代码。

## 2. 对外接口

```ts
RelayDeviceSnapshotReader.read(value: unknown): ReadonlySet<string> | null
```

返回一个新的只读 `Set` 表示本次快照中的在线设备标识；`null` 表示快照不可用，调用方必须完全忽略该快照，不能据此判断任何设备离线。

## 3. 接受的输入

唯一接受的形状为：

```ts
{ devices: readonly { deviceId: string }[] }
```

每个 `deviceId` 必须同时满足：非空白字符串、按 Unicode 码点计不超过 128 个字符、没有控制字符。重复标识会合并为一个设备。

读取属性时发生的任何异常（包括 getter 抛错）都使整个快照无效并返回 `null`；绝不向调用方抛出原始异常。

## 4. 输出保证

成功结果不保留输入数组、输入条目或其属性对象的引用。调用方只能通过只读集合接口查询或迭代设备标识；后续修改原始输入不会改变已返回的结果。

## 5. 依赖边界

该模块不导入同级任务调度器、根模块、`relay-link`、路线库或任何运行时适配器。它只使用 TypeScript 和 JavaScript 标准库。

## 6. 验证要求

测试必须覆盖合法的单设备和多设备快照、重复标识、空数组、所有拒绝形状、非法标识、抛错 getter、输入修改隔离以及只读类型接口。模块范围变异测试必须达到 100%。
