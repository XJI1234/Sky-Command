# 电脑局域网公告器

状态：接口契约，2026-10-13。网络格式与固定参数见 docs/auto-discovery/WIRE-PROTOCOL.md。

- 宿主只在应用服务成功启动后调用 start；start 幂等，stop 幂等且终结对象，停止后不再重新启动。
- 一秒检查 WLAN 网卡，按地址/掩码唯一拥有 UDP socket；绑定成功立即双广播，之后周期重复。只筛选真实 WLAN 私网 IPv4 与有效连续 /1–/30 掩码，排除内部、虚拟、VPN/mesh 地址。
- 网卡替换先关闭旧 socket，无网卡时等待；创建/绑定/发送失败只发固定诊断码并在下一周期重试。相同诊断码 30 秒最多一次，不泄露异常、地址、硬件标识或身份 UUID。
- stop 同步失效所有通道、取消定时器并尝试关闭 socket；迟到回调不得发送、重建通道或记录旧错误。绝不增加手机连接或调用飞行业务。
- serverId 仅写入宿主 userData 的 discovery-server-id 文件，使用排他创建，小写 UUID 校验；无效文件/写入失败使宿主停用公告并记录诊断，不妨碍原手动连接。instanceId 每进程随机生成。
- 依赖可替换：网卡读取、socket、单调时钟、周期调度器与诊断回调。真实 Node UDP 适配器只负责 bind/setBroadcast/send/close；所有错误均进入公告器错误边界。
- 验证周期重复、双目标、真实掩码、网卡排除、IP/掩码替换、无网等待与恢复、同步/异步失败、停止/迟到回调，以及身份持久化。不把电脑发送成功当成手机收到或正式连接验收。

2026-10-16 增加可共享 UDP 39082 请求监听，独立失败/限频诊断/下一秒恢复，停止与迟到回调受同一来源代次约束。精确 ASCII `SKY_COMMAND_RELAY_DISCOVER_V1`、来源端口 39082、当前 WLAN 子网有效单播来源才回复；经匹配 WLAN 原公告 socket 单播原有公告，每网卡每秒最多 32 个来源、同来源最多一次，缓存最多 32。原有周期双广播及所有候选选择规则不变。请求协议与 Windows 入站规则见 WIRE-PROTOCOL.md。
